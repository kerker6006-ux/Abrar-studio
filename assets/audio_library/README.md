# Abrar Studio CC0 audio library

This folder contains 369 production audio files from four Kenney packs:

- Impact Sounds 1.0
- Interface Sounds 1.0
- Casino Audio 1.1
- Music Jingles

Each pack is released under Creative Commons Zero (CC0). Its original
`LICENSE.txt` is stored beside the audio. Source pages:

- https://kenney.nl/assets/impact-sounds
- https://kenney.nl/assets/interface-sounds
- https://kenney.nl/assets/casino-audio
- https://kenney.nl/assets/music-jingles

Abrar Studio also indexes `%LOCALAPPDATA%/AbrarStudio/AudioLibrary` and any
folders configured in settings. This lets a user add licensed collections such
as the Sonniss GDC bundle without redistributing those source recordings in the
installer.
