# Character lock and rig status

The included assets are immutable locked cutout assets derived from the approved character sheets. They provide exact recurring identity for previews and motion-comic production: the app never redraws Seo-yeon or Min-jun.

For full mesh deformation, hair physics, hand animation, and phoneme-level mouth replacement, create a layered Inochi2D/Godot rig while preserving the existing manifest IDs. Required production layers include face base, hair front/back, eye whites, pupils, eyelids, eyebrows, jaw, mouth visemes, torso, upper/lower arms, hands, hips, legs, shoes, tears, sweat, blush, and facial shadows.

A newly separated rig must be reviewed manually, assigned a new version, and checksum-locked. The existing reference sheets are flattened images; automatic separation cannot be considered perfect and is deliberately not presented as completed work.
