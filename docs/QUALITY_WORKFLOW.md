# High-quality episode workflow

1. Start from one of the four bundled dramatic templates.
2. Keep the hook under 3.5 seconds and vary shot duration between roughly 1.5 and 3.5 seconds.
3. Block every conversation with a speaker and a listener. Use gaze and listener reactions rather than leaving both actors static.
4. Use close expression cards for emotional dialogue and approved full-body views for entrances, exits, confrontation and physical staging.
5. Assign ambience to each location, then add timed foreground effects only where an action occurs.
6. Give each scene one musical intention. Abrar Studio ducks music beneath dialogue automatically.
7. Generate voice, review important takes, then keep approved WAV files cached.
8. Run Final Validation. Do not bypass a failed identity, voice, rig, acting, sound, music, pacing or continuity gate.
9. Render scenes at 1280×720 and 24 FPS. Review the full video before publishing.

The local verification sample uses synthetic test speech only. Real Korean acting is generated after installation with the user's replacement Gemini key.
